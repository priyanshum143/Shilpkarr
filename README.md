# Shilpkarr

**Shilpkarr** is an architecture and interior design practice rooted in Sirsa, working across Hisar, Panipat, and nearby towns. We design and deliver residential and commercial spaces—from drawings to execution—with an emphasis on light, proportion, and work that feels considered and personal.

This repository is the **static marketing website** for the studio.

### SEO

Pages include unique titles, meta descriptions, canonical URLs, Open Graph / Twitter tags, and JSON-LD structured data (business, breadcrumbs, projects). **`robots.txt`** points crawlers to **`sitemap.xml`** at **`https://shilpkarr.in`**. After deploy, add the property in [Google Search Console](https://search.google.com/search-console), submit the sitemap, and create or claim [Google Business Profile](https://business.google.com) listings for each office (Sirsa, Hisar, Panipat) with the same name, address, and phone as on the Contact page.
